# 📊Student Score Management System (C++)

## Project Overview

The Student Score Management System is a C++ console application that allows users to enter and manage the scores of 5 students.
Using arrays and loops, the program calculates the class average, identifies the highest and lowest scores, and displays all scores in the order they were entered. 

---

## 🎯Features

- Store 5 student scores in an array
- Calculate the average class score
- Determine the highest score
- Determine the lowest score
- Display all scores in the order entered
- Process data using loops and conditional statements

---

## 🛠️Technologies Used

- C++
- Arrays
- Loops
- Conditional Statements
- Input and Output Operations

## ⚙️Program Workflow

1. Enter scores for 5 students.
2. Store the scores in an array.
3. Calculate the total and average score.
4. Find the highest score.
5. Find the lowest score.
6. Display all scores entered.
7. Display the average, highest, and lowest scores.
